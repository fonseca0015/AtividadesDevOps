## 🛠️ Tecnologias e Conceitos Explorados

- **Versionamento & Governança:** Git, GitHub, GitFlow, SemVer (Semantic Versioning), Code Review
- **Automação & CI/CD:** GitHub Actions, Workflows YAML, Azure DevOps Pipelines
- **Containers & Infraestrutura:** Docker, Dockerfile, Orquestração com Kubernetes
- **Qualidade & Validação:** ESLint, Testes Unitários, Testes de Integração, Testes de Performance
- **Observabilidade:** Monitoramento contínuo de logs, métricas e tracing (Grafana, Graylog)
