# Registro de Atividades Práticas — DevOps

Este documento reúne e organiza todos os projetos, repositórios de entrega e atividades práticas executadas no decorrer da disciplina de **Integração e Entrega Contínua (DevOps)** na **FATEC Sorocaba**, sob orientação do **Prof. Me. Deivison S. Takatu**.

---

## 📋 Detalhamento dos Trabalhos Realizados

### Tarefa 02 — Gestão de Versões com Git, GitHub, Commits e Tags
- **Objetivo:** Construção de uma aplicação web estática (`index.html`, `style.css` e `script.js`), inicialização e parametrização do ambiente Git local via VS Code, versionamento no GitHub, registros atômicos de commits e marcação de versões de release através de tags semânticas.
- **Repositório da Aplicação:** [nicollylemos/LivrariaDevOps](https://github.com/nicollylemos/LivrariaDevOps)

### Tarefa 03 — Customização de Template React e Deploy Contínuo na Vercel
- **Objetivo:** Clonagem e adaptação de um modelo open-source em React com TypeScript, organização do ciclo de dependências com NPM, publicação no GitHub e estruturação de esteira com entrega contínua (CD) conectada à Vercel.
- **Repositório da Aplicação:** [nicollylemos/ProjetoGitTemplate](https://github.com/nicollylemos/ProjetoGitTemplate)

### Tarefa 05 — Automação de Workflow com GitHub Marketplace Actions
- **Objetivo:** Planejamento e construção de uma esteira no GitHub Actions aproveitando 3 Actions comunitárias do marketplace, garantindo execução automatizada em fases de montagem, validação e entrega.
- **Repositório da Aplicação:** [fonseca0015/projetodevopspipeline](https://github.com/fonseca0015/projetodevopspipeline)

### Tarefa 06 — Pipeline de CI no Gatilho Push e Estudo de Repositórios Públicos
- **Objetivo:** Implementação de pipeline orientada a eventos de push na branch principal (`main`), aliada ao estudo analítico da engenharia de CI em grandes ecossistemas abertos (Vue.js, Spring Boot e NestJS).
- **Repositório da Aplicação:** [fonseca0015/projetodevopspipeline](https://github.com/fonseca0015/projetodevopspipeline)

### Tarefa 07 — Suíte de Testes Automatizados Integrada à Pipeline
- **Objetivo:** Desenvolvimento de testes em múltiplas camadas (isolados/unitários, integrados e de desempenho) associados a uma esteira declarativa em `.github/workflows/` para bloquear regressões antes de qualquer liberação.
- **Repositório da Aplicação:** [nicollylemos/Atividade07DevOps](https://github.com/nicollylemos/Atividade07DevOps)

### Tarefa 09 — Documentação Abrangente e Especificação Técnica em README
- **Objetivo:** Estruturação da documentação completa de um sistema (arquitetura, requisitos, decisões de projeto) e elaboração de um README padronizado e seguro com guia reproduzível de instalação e testes.
- **Repositório da Aplicação:** [tutuca07segundo/EcommercePWA](https://github.com/tutuca07segundo/EcommercePWA)
